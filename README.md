# RAELDATA – Website

Website von RAELDATA (raeldata.de) – Beratung für EDI, eProcurement und elektronische Rechnungsverarbeitung.

## Technik

- Vite, React, TypeScript, Tailwind CSS, shadcn/ui
- Hosting: Hostinger (automatischer Build aus dem Branch `main`)

## Lokal starten

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```

Das Ergebnis liegt im Ordner `dist/`.
